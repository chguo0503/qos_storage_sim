## 已核验的公式与边界

| 公式 | 审核结论与必要条件 |
|---|---|
| `B=V/C` | V用GiB、C用秒；B是画像参考速率。同请求内部相邻层读取量相同，才直接配对。 |
| `rho=32*sum(n*V)/(容量*sum(n*C))` | 按纯计算时间加权，8层公因子抵消。接近1不代表逐盘逐时欠载。 |
| `nS/nL=(b_target*CL-VL)/(VS-b_target*CS)` | 目标带宽须严格位于两类B之间；整数配比需重新核rho。 |
| `P=8*sum(n*C); W=7*sum(n*w); F=sum(n*d_L0); U≈P/(P+W+F)` | 是固定完成混合近似；7个内部周期与首层分别记账。有限窗、空闲仍按真实时序计算。 |
| `wS_needed=(8/7)*(1/U_target-1)*CS/f` | 只在短内部等待、其他等待均为0时成立；f是输入纯计算占比，不能换成窗口占卡比例。 |
| `D=C+w; mean_b/B=C/D` | 同周期同字节量的事后恒等式；不是瞬时U或排队预测。周期汇总按持续时间加权。 |
| `U[T]=实际计算重叠时间/(32*T)` | 固定完整分母，保留IO等待、空闲；窗口边界计算区间要裁剪。 |
| `VL/总容量`与`tau+VS/50` | 前者只是读取尺度，后者是首次接收后的完成时间下界；盘与链路流水重叠，不能机械相加。 |
| `U<=min(1,1/rho)` | 限完整批次共同分母或稳定完成混合，不能直接套任意两秒窗口。 |
