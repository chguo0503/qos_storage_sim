# 离线计算相位校准：可行条件和实验边界

本页说明构造条件。固定输入的两次完整重放现已完成：单轮对齐成功，长期保持失败，详见 README.md；下面的条件式推导不构成长时间相位锁定证明。

## 补齐计算，而非插入等待

在每卡 `A,B,B` 的末尾 B 上，记其首层计算开始为 `s_i`，每层纯计算为 `C_i`。如果 B 的 L1–L7 I/O 都及时完成：

```text
B 完成时刻 e_i = s_i + 8*C_i
选择共同结束时刻 E >= max_i(e_i)
新 C_i = C_i + (E-e_i)/8
```

若旧 C 都是 C0，也可以写为 `(E-s_i)/8`。较早的卡被分配稍多的计算工作量，晚卡不额外等待。这是预先冻结的不同计算请求，不能伪装成原来的两个精确 data 画像。

新增加的计算量是 `sum_i(E-e_i)` 卡毫秒/轮，必须计入利用率的分子，也必须单独披露。它会增加工作量与周期时长，不能把增加计算本身当调度器效率提高。

## 为什么旧 s_i 可能仍然有效

本实验 OD 的路径和 CIR 不依赖请求 C。B0 一开始便预取 B1；这次 I/O 的释放时刻不取决于 C。改变 C 最早能通过“B0 算完、随后开始 B1、释放 B2”影响其他卡。

因此一个方便的充分条件是：

```text
Delta = max_i(s_i) - min_i(s_i)
min_i(new C_i) > Delta
```

这保证所有卡 B0 都开始后，才可能出现被修改 C 影响的首个计算完成事件。所以保持 V/placement 不变时，这一批旧 s_i 在修改 C 后仍然成立。

不满足该条件不代表必然不可行，但不能直接照抄旧时序；早卡新发的 B2 可能改变晚卡 B0，必须重新冻结输入并重放。用实际 `s_i+new C_i > max(s_j)` 逐卡检查是更直接的充分判据。

另外两项条件独立且不可省略：全部 B 内部层 I/O 隐藏；下一轮 A0 在 B 计算完成之前就绪。否则 `e_i=s_i+8*C_i` 或“B 同时结束→A 同时开始”会失效。

## 单次校准不保证永久重复

第一次 A0 是冷读，后续 A0 已经预取，因此第一轮与后续轮不是相同边界条件。允许首轮一组固定尾 B 参数、此后另一组固定参数；但不能运行中根据误差重新算 C。

复用每卡每个位置的物理 KV 前缀，会让后续请求的实际 Ring Hash 分盘量重复。各卡物理前缀不同、逻辑请求 ID 唯一，不改放置算法。但这属于重复访问固定前缀的对抗性静态输入，不代表普通随机新前缀。

即使 A 同步、盘队列与链路已空，调度器的轮转游标、事件同刻顺序、客户端 RNG 状态也未必相同。核心 `_handle_client_submission` 每次对 ready NPU 使用同一个连续推进的 RNG shuffle；不能声称其每轮重置。OD 独占路径和同刻分批提交可能弱化其影响，但是否足够必须靠原生长期重放核实。

如果固定参数只同步一次，随后散开，说明本次固定点构造失败；不能增加隐藏 barrier 或无限逐周期调参。

## 画像真实性

直接改 C、保持 hit/miss 和读取量不变，只能叫合成计算画像。若进一步用 miss 插值来实现目标 C，在总长度固定时，hit 和 V 都会变化，原来的 s_i 与放置随之失效。可以研究保持 hit 不变而同时改变 total 和 miss，但新的 C 仍需合法数据模型/测量依据，并重新完整验证；插值不是实测。

本轮只做显式合成 C 的机制验证，不声称真实 data 行已经实现此相位锁定。

## 长期平均如何判定

若一个重复周期长度为 P、32 卡的计算总量为 W_card_ms，则跨很多完整周期：

```text
长期 U = W_card_ms / (32*P)
```

周期内可以先低后高，并不要求每个 2 秒窗口都低。但必须验证头几轮和后几轮的周期形态没有持续恢复，且统计窗内所有卡仍有输入。用全请求排空均值替代这个条件会把尾部空卡混进去。

原始 data A128K/miss256 的 C 约 6.024 ms；B128K/miss4096 的 C 约 93.017 ms。同步 A 阶段每卡需要大读取、计算短，可造成较多 I/O stall；随后 B 长计算能隐藏读取。如果每轮真正恢复到同一相位，低利用率阶段才有机会反复出现。这个数学机制仍需固定输入验证，不是已经完成的证明。

## 完整重放给出的边界

两次校准的目标轮均满足：B0 起算未改变，B 完成差从几十毫秒降为严格 0。第二次冻结输入的前两轮同步，第三轮偏差 0.180435 ms，之后逐渐放大；OD U 在 [12,14)、[14,16)、[16,18)、[18,20) 依次为 87.7768%、90.0878%、93.3694%、96.2421%。全部早于首张卡排空。B 内部 I/O 始终隐藏、下一 A0 始终提前就绪。

因此需要修正的逻辑是：`e_i=E` 只约束计算相位，不固定调度器完整历史状态。少量固定 C 向量未能在本实现中产生稳定重复轨道；这不是“离线补偿永远不可能”的证明，也不能根据一次对齐声称成功。两次尝试后已停止。
