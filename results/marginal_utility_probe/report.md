## 结论

- Marginal fixed 在 6/6 个场景的 request 指标高于 baseline，在 2/6 个场景高于 best-fixed。
- Marginal joint 在 6/6 个场景的 request 指标高于 baseline，在 3/6 个场景高于 best-fixed。
- 联合 Path 选路在 5/6 个场景提高 request 指标，在 3/6 个场景提高 fleet 指标。
- 这是零配置延迟、命令边界重配置的在线 heuristic 对比，不应称为理论最优。
